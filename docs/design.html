Derrick is the Dungeon

Design bible for an anatomy & physiology study roguelike set inside a guy named Derrick. Every build session reads this first.

Session rules

  • Renamed. The game was called “Marrow Depths” when the task cards were written. Any card that says Marrow Depths means this game. The artifact's title is Derrick is the Dungeon (if it already exists under the old title, find it by either name and retitle it). Where a card and this doc disagree, this doc wins, including the phase table below.
  • Purpose: a study tool for an intro A&P student (fetal pig dissection, plastic-model lab practicals). The game exists to make studying stick. Never let scope grow beyond this doc without asking the user.
  • Be token-frugal. The user watches usage. Do only your phase part. No speculative features, no repeated render/check loops (one preview look max).
  • Source of truth is GitHub: craigheadwilliamj-design/derrick-is-the-dungeon (public). If it isn't attached to your session, attach it with add_repo (push access) and clone it. Game code lives in game/; this doc lives at docs/design.html (keep both copies in sync if you change the design). Work on a branch named phase-<id> (e.g. phase-1a) from the latest main, commit, push, and open a pull request to main. The user merges it before starting the next card. Never commit lab images, study materials or personal data: those live in the user's claude.ai account storage, and the repo is public.
  • Where the game is played: one private claude.ai artifact titled Derrick is the Dungeon, published from the repo's game/ folder as a multi-file artifact (file_path = game/index.html, root = game, files = the other files). Phase 1a creates it and writes its URL into README.md. Later phases republish to that same url.
  • Load the artifact-design guidance (via quickstart) and the artifact-capabilities skill before writing page code.
  • Explanations shown to the player must be accurate A&P. If unsure, leave it out.
  • Mockup for look and feel: https://claude.ai/artifact/RR1EP1DFkhhLXZeYDGg8KW

Premise

The dungeon is a man named Derrick. You are one of his white blood cells. Derrick does not take great care of himself, and what he does to his body changes the world: his choices become region modifiers, chronic conditions, and the running joke NPCs comment on. Every consequence must be real physiology; the humor is how the fact sticks.

Tech

  • Plain JavaScript, no framework, no engine. Canvas or a DOM grid for the glyph map. Classic roguelike glyphs (@ # . + >, letters for monsters), colored per region. Single dark visual world.
  • Content is data. Questions, items, enemies, classes, subclasses, NPCs, regions live in data/*.js tables. Logic in js/*.js. Balance numbers in one js/settings.js.
  • Files: index.html, js/ (engine, combat, effects, dungeon, ui, save, editor…), data/.
  • Saving: db + user capabilities, private path data/users/<id>/… (save doc, custom questions, image-question records). localStorage mirror as fallback. Store per-question stats and per-region last-reviewed timestamps.
  • Images: assets capability for lab-manual screenshots and dissection photos.
  • In-game question writing (phase 4): sample capability.
  • Works on phone (tap controls, d-pad) and laptop (WASD/arrows, number keys for answers).

The effect system (backbone)

Gear, class passives/actives, subclasses, items, buffs, set bonuses and legendaries are all effects: {trigger, condition?, result}. Combat and travel only read final stats and fire triggers.

triggers: fightStart, turnStart, onLight, onHeavyCorrect, onHeavyWrong,
          onBlock, onHit, onBigHit, onKill, onQuestionCorrect, onQuestionWrong, onQuestionAsk,
          travelSegment
conditions: enemyType (bacteria|virus|fungus|protozoa|worm), isBoss,
            hpBelow, firstHeavyOfFight, answeredFast, beatenBefore, any:[…] (OR of conditions)
results: damage, damageMult, heal, stat+, atp+, poison(n turns), shield,
         removeWrongOptions(n), execute(threshold), summonAlly, repeatHit,
         travelSpeed, revealNPCs

New content should almost always be new data combining existing effects.

Combat

  • Turn-based. Enemy telegraphs its next move: attack, big attack, defend, or question.
  • Player: light (small, always lands), heavy (asks a question: right = big damage, wrong = whiff and open), block, ability (costs ATP), item.
  • Enemy question move: right = player buff, wrong = enemy buff. Regular enemies ~once per fight; bosses every ~2 turns with bigger swings.
  • Every answer shows a short explanation. Number keys 1–4 answer.
  • Damage = Power × action multiplier × matchups − enemy defense. Strong class/pathogen matchup ≈ +50%.
  • Abilities never skip a question. Questions must stay the best move (light-attack spam must be slow and costly).
  • Target pacing: a question every 20–30 s of play.

Subclasses (phase 5, picked at thymus ~lv 10)

Berserker: NET Weaver / Respiratory Burst. Wizard: Plasma Cell / Memory B Cell. Rogue: Cytotoxic Assassin / Regulatory T (debuffer). Paladin: M1 Crusader / M2 Warden. Ranger: Worm Hunter / Toxin Trapper. Bard: Histamine Herald / Heparin Keeper. Each = passive tweak + active upgrade.

Enemies

  • Pathogens: bacteria, viruses, fungi, protozoa, worms. Type only sets matchup bonuses; no special behaviors.
  • Mild and common early (cold, strep throat, acne bacteria, athlete's foot, pinworm, cold sores, pink eye, ear infection, norovirus, UTI); serious later and as bosses (TB, plague, meningitis…).
  • Bosses: more HP, harder hits, more questions, one unique legendary drop themed on the pathogen (e.g. Polysaccharide Capsule). No gimmick phases.
  • Microbiology is flavor only: one-line codex blurb, never quizzed.
  • Clots and plaques are vessel hazards (block or narrow paths), not enemies.

Traps

  • Hidden trap tiles in vessel segments and dungeon floors. Stepping on one triggers a pop quiz: one multiple-choice question. Wrong = damage (scaled in settings), right = disarmed plus a little XP. Always show the explanation.
  • Questions come from the current region (vessels: blood and cardiovascular). Glyph ^ once revealed or triggered. Flavor names per place (turbulence in the aorta, a bone shard in the femur, an acid splash in the stomach).
  • Frequency tuned so traps add questions without slowing travel: about 1–2 per trip, a few per floor.

NPCs

  • Town: plasma cell (shop), mast cell (inn), helper T (quests/bounties).
  • Traveling merchant: dendritic cell. Random dungeon floors, limited stock (sometimes unique), rest at ~2× inn price, tips about fading regions.
  • Native cells, one per dungeon floor (osteocyte, neuron, parietal cell, podocyte, cardiac myocyte…): 1–2 lines of dialogue that teach a fact, one question drawn from the player's weak spots. Right = loot, wrong = explanation only. No combat.
  • Derrick commentary: every NPC has lines reacting to Derrick's current events and conditions, in character, and accurate. Examples: osteocyte after a broken leg, “Fourteen years in this lacuna and he jumps off a roof for a video.” Podocyte after a night out, “No ADH. None. Do you know how much filtrate I'm dealing with?” Mast cell after a salad, “He ate a vegetable. Voluntarily. Rooms are half off.”

Economy

  • Glucose = currency (enemies, chests, vessels, NPCs, outbreaks). ATP = mana: small trickle per correct answer, big refills only by converting glucose at towns (≈30 ATP per glucose flavor) or pricey ATP Reserve.
  • Classic RPG attrition: inns give a full restore for glucose. Healing carry cap: 3 Cytokine Tonics.
  • Consumables: Cytokine Tonic (heal), ATP Reserve, Complement (next heavy +50%), Mucus Ward (block next hit), Fever (+damage, self-damage per turn), Interferon (bonus vs viruses), Antibiotic (bonus vs bacteria, useless vs viruses), Lymph Drain (escape to nearest node).

Gear

  • Slots: weapon, armor, 2 accessories. Rarity: Common (white), Uncommon (green), Rare (blue), Legendary (gold, boss-only).
  • Hand-designed fixed items, no random stats, built from the effect list. ~60 in phase 4, ~150 by phase 5. Every item's description is a true A&P/immunology fact.
  • Examples: Antibody Sword, Lysozyme Axe, Perforin Dagger, Respiratory Burst Staff, Defensin Mace, Major Basic Protein Bow, Histamine Lute; Keratin Plate, Myelin Sheath, Tight Junction Mail, Mucous Membrane Robe; Selectin Boots (travel speed), Chemokine Compass (reveal NPCs), Toll-like Receptor Ring, Melanin Charm. Regional: Hydroxyapatite Shield, Osteon Helm, Actin-Myosin Gauntlets, Purkinje Whip, Pepsin Blade.
  • Sources: towns (basic), dungeon chests (system-themed), merchant, boss legendaries.
  • Phase 5: 3-piece set bonuses (e.g. Barrier set) and rule-changing legendaries (“heavy attacks hit twice”).

Study systems

  • Multiple choice only. Text questions: {id, system, q, answer, wrong[3], explain, source}.
  • Image questions (label-cover, like Anki image occlusion): upload a lab-manual screenshot or dissection photo, drag boxes over labels, type each label. Each box = a question; wrong options come from other labels on the same image. Tag source: human-model or fetal-pig; question shows the tag; filter by source. Never mirror images.
  • Question picker: weighted toward missed, unseen and stale questions. NPCs weight weak spots harder.
  • Mastery per region from accuracy + recency; fades over ~2 weeks, computed from timestamps on load. Outbreaks spawn in faded regions with boosted loot.
  • Missed-question review list with explanations; post-mortem screen on death lists the run's misses.
  • Flag-a-question button. Generated questions are reviewed by the player before going live.
  • Questions come from the user's own study guides and lecture notes (blood and lymphatic first). Starter questions are placeholders, marked as such.

Derrick's life (replaces generic outbreaks)

  • Each session (or day) rolls what Derrick's been up to. Events are region modifiers built from existing effects: pathogen mix, hazards, player buffs/debuffs, loot and glucose. Events land preferentially in the player's most-faded regions, with boosted loot.
  • Acute (session/day): big night out (alcohol suppresses ADH → dehydration: sluggish vessels, harsher kidneys, busy liver); all-nighter (high cortisol suppresses immunity → lower Defense); didn't wash hands (influenza in the lungs); sunburn (UV-damaged skin dungeon); untrained 10K (muscle microtears; NPCs debunk the lactic-acid soreness myth); broken leg (inflamed femur, debris, macrophage bonus, osteoblast NPCs).
  • Positive: flu shot (bonus vs influenza; synergizes with Memory), ate well and slept 8 hours (small global buffs, NPCs shocked).
  • Chronic (whole playthrough, mainly in NG+): type 2 diabetes (more glucose drops, but glycosuria: lose some glucose each pass through the kidneys; weaker healing), hypertension (worse vessel hazards), smoking (cilia impaired: nastier lungs, weaker Mucus Ward).

Derrick's chart

  • A status screen styled as a medical chart: heart rate, blood pressure, blood glucose, hydration, temperature, current events and conditions, each beside its normal range.
  • Values reflect his current state (night out → dehydrated, diabetes → high glucose). Opening it is a quick review of normal values.

Death & long game

  • Death: respawn at marrow, may switch class, lose half carried glucose, current dungeon resets. Keep levels, gear, mastery, missed list, routes.
  • Reinfection (NG+) after all bosses: “Derrick is now 45.” Tougher strains, higher loot tier, one or two chronic conditions.

    Static stat effects are read by DD.stats.compute(). Fire order: class → subclass → gear → set → buffs → event. Buffs with turns tick down at turnStart.
  • Stats (class ratings are the bible's 1–5 numbers): maxHP = 20 + 8·hp + 4·level. power = 2 + 1.2·pow + 0.6·level. defense = 0.8·def + 0.2·level. maxATP = 10 + 4·atp. XP to next level = 20·level.
  • Combat math: dmg = max(1, round(power × actionMult × matchup × fxMult − targetDef)). Light 0.6, heavy-correct 1.8, heavy-wrong 0 (and the enemy's next attack does +50%). Block cuts incoming damage by 60%. Incoming enemy attacks deal max(minHit, round(atk × mult − defense × defenseWeight)), with minHit 2 and defenseWeight 0.5 in js/settings.js (added in 1a, since full Defense made early enemies deal 1 damage). A strong matchup is 1.5. Enemy intents: attack 1.0, big attack 1.8 (telegraphed with a red "!!"), defend (halves damage taken this turn), question. An enemy question's buff to the player, if right: +25% damage for 2 turns or heal 15% maxHP. To the enemy, if wrong: heal 15% or +25% damage for 2 turns. Regular enemies use the question intent about once per fight; bosses every 2nd turn.
  • Enemy scaling: level = playerLevel + floorIndex. HP = 12 + 5·level, atk = 2 + 1.1·level, def = 0.3·level. Bosses get ×3 HP and ×1.4 atk. The pathogen roster is picked by level band: mild under level 5, moderate 5–9, serious 10+. Regular rosters are your choice, but they must be pathogens that really infect that region. Codex blurbs are one accurate line, never quizzed.
  • Visual language: follow the mockup. A single dark world, tokens on :root with color-scheme:dark, Pixelify Sans for display, Atkinson Hyperlegible for body text, JetBrains Mono for glyphs. Each region has an accent color in data/regions.js. Phone width (360px) must work with an on-screen d-pad. Keyboard: arrows/WASD to move, 1–4 to answer, L/H/B for light/heavy/block, A for ability, I for items. Respect reduced motion.
  • Accuracy: every explanation, codex line, item description and NPC line must be correct intro-level A&P. If you aren't sure, cut it.
  • Checks, kept cheap: node --check on every js file; one headless Playwright load of the local index.html that walks into one fight and reports console errors; one Artifact preview look at most. Then publish. Report what you tested and what you couldn't (for example, db behavior outside the viewer).
  • Don't: add features from later phases, rename existing ids, or change save shapes without a migration (bump v and migrate on load).

1a · Core engine

  • Boot: title screen ("Derrick is the Dungeon", Continue / New), then the Bone Marrow menu. The menu lists every region from data/regions.js with its name, system, mastery meter and status. Only bloodstream and spleen are playable. The rest show "No questions yet".
  • Floors: 3 per dungeon, the last is the boss floor. Grid 48×32. 6–10 rectangular rooms (5–11 × 4–8), no overlap with a 1-tile margin, connected in sequence by L-shaped corridors plus one extra random connection for a loop. Doors + where corridors meet rooms. The player starts in room 0 and the stairs > go in the farthest room. On the boss floor the boss stands in the farthest room and the exit appears when it dies. 4–7 enemies per floor, never in room 0. 1–3 glucose pickups $ (cosmetic until 2b; just count them).
  • FOV: radius 7, Bresenham line of sight. Explored tiles stay dimmed. Enemies that can see you chase within 8 tiles (greedy step, no stacking). Bosses don't move. Moving into an enemy, or an enemy moving into you, starts combat.
  • Rendering: a canvas sized to its container. The camera centers on the player and shows about 25×17 tiles, with tile size = min(fit width, fit height). Glyphs: @ player; lowercase letter per pathogen; uppercase for bosses (with glow); # walls in the region accent; · floor; + door; > stairs.
  • Combat overlay: the enemy glyph, name, type chip (bacteria, virus…), HP bar, and an intent chip for its next move. The player HP and ATP bars. Actions: Light, Heavy, Block, Ability (Antigen Presentation, 6 ATP: removes 2 wrong options from the next question shown), Flee (disabled until 2b). Heavy opens a question in the same panel. The explanation shows after every answer. Turn log of the last 3 lines.
  • Class: Macrophage · Paladin only (hp 5, pow 2, def 4, atp 2). Passive Phagocytosis: onKill → heal 12% maxHP. ATP regen: +2 per correct answer. All abilities run through the effect engine, even this first one.
  • Death in 1a: a simple "Your cell has died" screen, then back to the marrow with HP restored and the dungeon reset (full rules come in 2b).
  • Data: data/enemies.js entries are {id, name, type, glyph, regions:[…], band:"mild|moderate|serious", codex}; bosses use band:"boss" and boss:true. Bloodstream bands: mild Streptococcus pyogenes (bacteria), Candida albicans (fungus), cytomegalovirus (virus). Moderate Staphylococcus aureus, hepatitis B virus. Boss Plasmodium falciparum (protozoa, malaria; infects red blood cells). Spleen: mild Epstein-Barr virus, Streptococcus pneumoniae. Moderate Salmonella Typhi. Boss "Epstein-Barr Colossus" (EBV; mononucleosis enlarges the spleen).
  • Starter questions: 15 for blood and 15 for lymph, accurate intro A&P, placeholder:true, source:"starter". Cover plasma proteins, formed elements and their functions, hemoglobin, erythropoietin, hemostasis, ABO/Rh; lymph formation and flow, lymphoid organs, innate vs adaptive, B vs T cells, antibody classes.
  • Done when: you can clear both dungeons on a phone-width viewport and a laptop, the save survives a reload, and question stats and mastery update.

1b · Label-cover image editor

  • Add assets:{} to capabilities (restate db and user). If claude.use("assets") is null, show "Image questions need the claude.ai viewer" and hide the editor.
  • Editor screen (from the marrow menu, "Lab images"): pick a file, or paste with the paste event. Choose the system and the tag (human model / fetal pig), and an optional title. Show the image fitted to width. Drag with pointer events (mouse and touch) to draw a box, with a minimum size of 2% of width. Each box gets a text field for its label. Boxes can be moved, resized from a corner handle, and deleted. Save with an upload through assets.upload, then write the record img_<id> = {id, assetId, system, tag, title, boxes:[…], createdAt}.
